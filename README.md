# Oak & Ember Press — website

Brand home for Oak & Ember Press. Printable binders, planners, recipe packs, and the tools that make them.

- `docs/DESIGN_BRIEF.md` — theme directions, chosen direction (One Spark, phone-first), site map, stack, Oracle Cloud deployment plan, milestones.
- `docs/concept/` — static visual concept of the chosen direction (open `index.html`).
- `public/brand/` — the gold logo, copied from `ebook-pipeline/assets/brand/`.

Product data comes from the `ebook-pipeline` repo and is never retyped here.
