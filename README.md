# Oak & Ember Press — website

Brand home and shop front for Oak & Ember Press. Printable binders, planners, recipe packs, and the tools that make them.
Live at https://oakandemberpress.com once provisioned; see `infra/PROVISION.md`.

## Run it
```bash
npm ci
npm run sync-catalog -- --pipeline ../ebook-pipeline   # regenerate src/content/products from the binder specs
npm run dev                                            # http://localhost:4321
npm run build && npm run preview
```

## Layout
| Path | What |
|---|---|
| `src/components/EmberLayer.astro` | The ambient ember canvas. Persists across page transitions, re-tints to each page's `data-glow`. |
| `src/components/Scroller.astro` | Home-page scroller: embers form the mark, then a binder, a plate, a workflow graph. |
| `src/components/BottomNav.astro` | Thumb-reach pill nav. Same four doors on every page. |
| `src/lib/embers.ts` | Shared particle helpers and the stage shapes. |
| `src/content/products/*.json` | Generated by `scripts/sync-catalog.mjs` from `ebook-pipeline/templates/workbooks/*.yaml`. Don't hand-edit. |
| `src/data/site.json` | Name, tagline, domain, Etsy URL (empty until the shop opens), contact email. |
| `src/data/lines.json` | The product lines and their hues. Add a line here and it appears on the home page. |
| `infra/` | Caddyfile, cloud-init for the OCI VM, and `PROVISION.md` (VM, DNS, deploy secrets, domain email). |
| `.github/workflows/deploy.yml` | Build on push to `main`, rsync `dist/` to the VM, reload Caddy. |
| `docs/DESIGN_BRIEF.md` | Direction, rationale, site map, milestones. `docs/concept/` is the static concept it came from. |

## Adding a product's gallery
Run the pipeline so `output/<run>/previews/*.png` exists, then `npm run sync-catalog`. Cards are copied into `public/catalog/<slug>/` and the product page uses them.
